What this demo is. The repo is a runnable Python gateway on litellm.Router that fails over across OpenAI → Anthropic → Gemini, retries with cooldown, and tracks spend per request (6 offline tests; runs with zero API keys in mock mode). This page simulates that router's policy in the browser so you can flip providers into rate-limit, latency or outage states and watch the caller keep getting answers from one stable interface — while spend accrues and the budget guard hard-stops calls when exceeded. Failure-mode spec and routing policy by Keshvi Pipwala; implementation AI-assisted. It grew out of GitSense, where a single-provider rate limit took down a working agent.
