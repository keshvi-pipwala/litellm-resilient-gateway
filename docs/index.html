About this demo. The repository is a runnable Python gateway on litellm.Router: strict primary → fallback chain across OpenAI, Anthropic and Gemini, retries with cooldown, per-request spend tracking with a budget guard, six offline tests, and a mock mode that runs with zero keys. This page reproduces that router's policy in the browser so you can flip providers into rate-limit, timeout or outage states and watch the caller keep getting answers from one stable interface while spend accrues and the budget guard hard-stops calls once exceeded. Failure-mode spec and routing policy by Keshvi Pipwala; implementation AI-assisted. It grew out of GitSense, where a single-provider rate limit took down a working agent.
